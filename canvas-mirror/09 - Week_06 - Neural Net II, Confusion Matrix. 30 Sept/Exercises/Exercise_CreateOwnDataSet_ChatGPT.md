# Exercises - ITA - Week 6: Create your own dataset

Source: `Exercise_CreateOwnDataSet_ChatGPT.pdf` (1 page). Groups of 2-3.

- Use ChatGPT to create your own dataset, saved as an Excel file and read into your Python program, or inserted directly into the program. The dataset should have at least 1 parameter (y) that a machine learning algorithm can be trained to predict from the other parameters.
- Use ChatGPT to create Python code that splits the dataset into test and training set.
- Use ChatGPT to create an MLPClassifier (sklearn) that classifies your dataset.
