# Shakespearean Monkey Problem (short GA task, English)

Source: `Genetic Algorithms/ShakespereanMonkeyProblem.pdf` (1 page). Alternative/shorter statement of the same task as `ShakespereanMonkeys`.

Make a Python program that solves the Shakespearean Monkey problem:

- Initialize a population of strings.
- Make a **fitness function** that gives a value for a string (how close is it to the solution).
- Assert fitness for all strings in the population. Let the **best 10 percent** go straight to the next population. Fill the remaining **90%** with **crossover and mutations** of the best ones.
- Start over with assigning fitness, and so forth. Repeat until you reach the string **"To be or not to be.."**

Inspiration: https://faun.pub/shakespeares-monkey-and-the-genetic-algorithm-9f6dec47cea4

Use Google and ChatGPT to come up with a working program.
