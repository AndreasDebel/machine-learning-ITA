# Shakespearean Monkey Problem (exercise, Danish)

Source: `Genetic Algorithms/ShakespereanMonkeys.pdf` (2 pages). Faithful English rendering.

Monkeys are placed at typewriters and should type "To be or not to be that is the question", each keystroke a random key. They face a huge challenge composing **39 characters** in the right order. We try to help them with a Python program based on a **genetic algorithm (GA)** and random strings (correct length 39, possibly generated by the monkeys or a random generator) that generates the sentence "To be or not to be that is the question".

## a) Fitness function

Using GA terminology (a potential solution = "chromosome", each character = "gene"): how would you design a fitness function?

## b) Random baseline

Make an algorithm that generates **10,000 or more random strings** and computes which has the highest fitness (baseline for comparison).

## c) Hill climbing

Random guessing is inefficient because it does not exploit good solutions already found. In hill climbing, start with a random solution and look at its neighbours. A neighbour of a string is another string differing in one or more characters (experiment with different definitions of "neighbour"; can the search be made efficient so searched neighbours are not worse than the current solution, etc.).

Compute fitness for the neighbours, select the best neighbour, and use it as the starting point for continued search. Experiment with different neighbour definitions, number of iterations, etc.

## d) Genetic algorithm

From b) and c) you have two algorithms to compare against. Design a GA with suitable **mutation rate, crossover operation, population size and number of generations** that finds (or gets close to) the solution given the earlier fitness function.

Question: how does the GA perform compared to the random algorithm and hill climbing?
