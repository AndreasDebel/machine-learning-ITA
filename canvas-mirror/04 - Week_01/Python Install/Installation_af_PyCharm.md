# Installation of PyCharm

Source: `Python Install/Installation_af_PyCharm.pdf` (1 page, Danish; contains a screenshot of the download page).

- Course uses **Python** and **PyCharm** as editor. Install PyCharm before the first class.
- **IMPORTANT: download Community Edition, NOT Professional Edition.**
- Go to https://www.jetbrains.com/pycharm/download/, pick your OS (Windows, Mac or Linux).
- IMPORTANT: click the **black button** shown in the screenshot (the Community download).
- Follow the installer instructions; you may need to restart the computer depending on OS. Then start PyCharm.
- Test: create a new Python program, or use the Python command line and try the `print` command as on page 4 of the first chapter (slides).
- Helpful YouTube video (install + first Python program): https://www.youtube.com/watch?v=cHa85et7LK0
