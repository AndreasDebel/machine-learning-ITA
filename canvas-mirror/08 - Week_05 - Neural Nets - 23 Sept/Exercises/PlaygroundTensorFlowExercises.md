# Playground TensorFlow Exercises

Source: `PlaygroundTensorFlowExercises.pdf` (2 pages). Tool: http://playground.tensorflow.org/

## Exercise 1
Given the "Circles dataset" (here without noise; try to regulate noise level), using the ReLU activation function:
- How many hidden layers, with how many neurons, do you need to classify correctly?
- What is an appropriate learning rate (what is too low, what is too high)?
- Thickness of lines represents weight values. Mouseover a hidden unit shows what that neuron is doing.
- What is the smallest network that classifies correctly? Using which activation function?

## Exercise 2
Looking at the spiral dataset:
- How many hidden layers do we need to classify correctly (into something like the picture shown in the PDF)?
- Minimum number of neurons in the hidden layers?
- Proper learning rate for a "reasonable" training time (number of epochs)?
- Which activation function did you use?

## Exercise 3
Can you classify correctly (Exercise 2) with an even smaller neural net, using another activation function?
