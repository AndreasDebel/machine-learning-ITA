# Machine Learning - Week 5: Exercise Neural Net ChatGPT

Source: `Exercise_NeuralNet_ChatGPT.pdf` (1 page). Group work, 2-3 people.

1. Ask ChatGPT for 5 datasets, freely available for download, that can be classified with neural nets.
2. For one of these datasets, ask ChatGPT for Python code that can classify the dataset.
3. In the group, explain to each other what the suggested code does. Do you think it works?
4. If you have time, try to run the code.
