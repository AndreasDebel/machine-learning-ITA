# Running Jupyter - Quick Guide

Source: `RunningJupyter_QuickGuide.pdf`, 1 page. Author: Sila, March 2021.

1. Make a new environment (in a folder, e.g. `ex1`): https://docs.python.org/3/library/venv.html
2. Activate the environment (go to `Scripts`, run `activate`; the cmd prompt changes).
3. Install Jupyter (https://jupyter.readthedocs.io/en/latest/install/notebook-classic.html):
   - `pip3 install --upgrade pip`
   - `pip3 install jupyter`
4. Run Jupyter from the prompt: `jupyter notebook`
5. Need libraries in the notebook? Use `pip install mylib` in the cmd prompt.
