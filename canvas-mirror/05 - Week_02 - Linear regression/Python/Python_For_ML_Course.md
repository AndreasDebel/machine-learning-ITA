# Python for ML course

Source: `Python_For_ML_Course.pdf`, 3 pages. Author: Sila, August 26th, 2022.

Setup guide for Python and libraries.
- Python: https://www.python.org/downloads/
- 5 key libraries: scipy, numpy, matplotlib, pandas, sklearn. Instructions: https://www.scipy.org/install.html, or Hands-On ML (Geron) p. 40-43 (v1) / p. 46-48 (v2).
- Windows or less confident users: install the free Anaconda (includes everything): https://www.anaconda.com/download/
- Version check script (author's Spyder output): Python 3.6.3 Anaconda, scipy 0.19.1, numpy 1.13.3, matplotlib 2.1.0, pandas 0.20.3, sklearn 0.19.1. The script prints `sys.version` and each library's `__version__`. Older versions are probably fine; newer are probably better.
- More: Learn Python, http://www.learnpython.org/
