## Exercise 1
Ask ChatGPT how to make (say) 60 random points with an X and Y coordinate, in Python. The points must randomly be assigned to 3 different colors, where the groups are not mixed but centered in distinct clusters, and where it is possible (give and take a few outliers) to separate the groups with lines. Now make a plot of these points in Python.

## Exercise 1.2
Ask ChatGPT for Python code that can make (two) line(s) that separate the clusters. Ask ChatGPT for code that can plot this.
