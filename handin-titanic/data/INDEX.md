# Data files

`titanic_800.csv` is never changed. All other files are generated by `../clean.py`; re-run it after changing a step.

| File                      | What it is                                                                                                                         | Used by             |
|---------------------------|------------------------------------------------------------------------------------------------------------------------------------|---------------------|
| `titanic_800.csv`         | Raw data from Canvas, unchanged (incl. the 98 corrupted `Fare` values)                                                             | `clean.py`          |
| `titanic_800_cleaned.csv` | All row-level cleaning: `Fare` fixed, `Sex` → 0/1, `Age_missing` flag, `Embarked` filled + one-hot; all features kept              | `correlation.ipynb` |
| `titanic_800_model.csv`   | The cleaned file minus the dropped features: only the columns the model uses. `Age` still blank (filled after the split)           | `clean.py` (split)  |
| `titanic_800_train.csv`   | 80 % (640 rows) of the model file, stratified on `Survived`; `Age` filled with the training median; `Pclass`, `Age`, `Fare` scaled | `titanic.py`        |
| `titanic_800_test.csv`    | 20 % (160 rows), same steps, but the median and scaling come from the *training* set                                               | `titanic.py`        |
